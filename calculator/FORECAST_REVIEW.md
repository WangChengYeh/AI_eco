## 判讀口徑

| 檢查點 | 現行規則 |
| --- | --- |
| 營收與自用 | 對外收費才列收入；自用機器人、算力、發射與材料不虛增收入 |
| 獲利與投入 | 分部營業利益不等於淨利；製造投入進資產及完整capex，折舊與維修照計 |
| 降本 | 只降低合格現金成本，不任意抵銷材料及折舊，不重複計入自用節省 |
| 股票支付 | 成本保留、合格付款改股票、股數增加；不創造假收入或現金融資 |
| 現金 | 實為含短期投資的流動資金池；與經濟FCF、非現金對價分開 |
| 股數 | 期初已發行在外股數加發股／SBC扣回購；EPS用加權股數，年底估值用年底股數 |
| P/E | 年淨利×公司倍數÷年底股數；淨利不正才N/A，資金缺口另示 |
| SOTP | 各分部EV/Sales，扣公司成本、加流動資金、扣債務，除年底股數 |
| 太空算力 | 每月發射槽與MW推導投運，依逐台頻率乘有效月份，不套場址／全機隊封頂；製造無瓶頸仍付全額成本 |
| 發射頻率 | 主預測逐台按月相乘加總，沒有額外全機隊上限；每台頻率是模型假設，許可僅獨立資訊，不參與技術容量封頂。環評方案、擬議額度與核准許可分開 |
| 年度範圍 | 主預測只2027–2031；bear／bull是敏感度，不是修訂版 |

## 完成的驗證

最新回收與月度融資模型131項測試通過，主預測930項、兩組敏感度各920項公式勾稽；最新數字見[容量與財務重算](../research/starship_launch_capacity_2026-11-20.md)。驗證包括分部加總、損益、經濟及現金FCF、資金與債務遞推、股數及股票對價、估值、FSD車隊、算力計費、衛星資產／庫存、逐月部署與發射槽。HTML內嵌結果等於Python，兩個發布入口一致且可從乾淨環境重建。
