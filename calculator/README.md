# Tesla／SpaceX 年度 Forecast Calculator

同一份2027–2031條件式分析；Tesla 8項、SpaceX 11項業務。輸入、來源、計算與公開HTML相互對應。採Python標準函式庫，無需額外套件。

## 執行

從repo根目錄：

```bash
python calculator/run_pipeline.py
python calculator/forecast.py --help
```

Pipeline完成來源映射、假設搜尋覆蓋、單元測試、主預測與敏感度重算、財務／資產勾稽及HTML生成。只需重建頁面時可執行`python calculator/build_site.py`；完整發布仍應跑Pipeline。

| 檔案 | 用途 |
| --- | --- |
| `configs/current.json` | 唯一主預測參數，修訂歷史由Git管理 |
| `configs/reference_facts.json` | 有日期與來源的披露數據 |
| `configs/input_provenance.json` | 參數映射與分類；未覆蓋參數仍待校準 |
| `configs/user_assumption_research.json` | 每項使用者假設的搜尋與限制證據 |
| `forecast.py` | 逐月資產與逐年公司預測、CLI匯出 |
| `audit_model.py` | 獨立公式勾稽與HTML／Python一致性檢查 |
| `site_template.html`、`site_shell.html` | 固定網頁模板；不要手改生成HTML內的數字 |
| `build_site.py` | 從同一結果生成根目錄及docs入口、摘要與研究報告 |
| `forecast_summary.md` | 主預測摘要，金額十億美元、股價美元／股 |

`forecast_output/`為可重建輸出，不納入Git。`configs/example.json`、`optimus_10m.json`是歷史／示例檔，不控制公開頁面。`base`是主預測的程式識別碼；`bear`、`bull`僅供可選敏感度檢查，不是修訂版本。

## 當前資料基礎

2026Q3資產負債與2026-10-15已發行在外普通股作2027期初錨點，**假設至2026年底淨變動為0**。流動資金是現金及約當現金加短期投資的可動用資金池，並非僅GAAP現金；排除受限現金。債務含流動及非流動借款與融資租賃。SpaceX股數含A、B類，不能只用自由流通股；亦不能把EPS加權股數當期末股數。來源與組成列在`reference_facts.json`。

其餘產銷量、成本、周轉資金、資本支出、費用、費率曲線、稅率、股票支付及估值仍含大量模型假設，狀態為`partially_anchored`，不代表已完整校準。財務錨點不是2026年末實績。

## 財務、股數與估值

營業利益＝分部營業利益合計−公司費用（含另列SBC及內用機器人折舊等）。淨利再扣利息與稅；分部營業利益不是分部淨利。經濟FCF＝淨利＋折舊攤銷−完整資本支出−營運資金增加。以股支付的成本與投入仍留在損益／資產／經濟FCF中。

現金FCF＝經濟FCF＋非現金SBC＋直接股票支付。股票支付是將合格現金付款轉為股權對價，不是假收入，也不等於收到現金融資；新增股數依協議參考價計入。現行假設100%接受，Tesla 250、SpaceX 100美元／股，並非已簽約條件；只在資金缺口時使用。保留負債利息及最低資金需求檢查。

P/E股價＝年度淨利×公司P/E÷年底股數；Tesla 45倍、SpaceX 40倍仍是假設。報表EPS使用期內加權股數，故不要將該EPS直接乘倍數與期末估值混用。淨利不正時P/E顯示N/A；資金缺口另外警示，不用N/A隱藏條件估值。

SOTP股價＝（各分部收入×各自EV/Sales−公司成本資本化＋流動資金−債務）÷年底股數。這是另一套估值，不是每個業務都40倍本益比；現金、債務及稀釋須同步變動。模型合併輸出只是每年獨立的假想換股快照，不代表完成交易，也沒有交易後資產負債遞推。

## 驗證與限制

測試涵蓋營運、退役、爬坡、現金及稀釋，也檢查來源漂移、2028閏年、HTML與Python一致及乾淨重建可重現。`audit_model.py`獨立勾稽損益、現金、股數、資產、MW與發射槽；這些驗證證明計算一致，不能證明未來付費需求、供給、許可、成本或估值會達成。
