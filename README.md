# AI_eco｜AI 經濟學

研究數位 AI 與實體 AI 如何改變生產成本、競爭、資源交換與股東購買力。核心是兩個可分開驗證、也可能互相強化的假說。

## 核心理論

| 理論 | 當前命題 | 成立條件 |
| --- | --- | --- |
| [001：股權交換經濟](theories/001_equity_exchange_economy.md) | AI 核心企業的股權可能由資產與募資工具，擴展為直接交換企業及資源的對價，進一步形成支付網路 | 交易對手持續接受、可轉讓與再流通、價格及結算制度可行 |
| [002：AI 生產、競爭與供給型通縮](theories/002_ai_supply_deflation.md) | 數位與實體 AI 持續降低同品質產出的完整成本；降價可能淘汰高成本競爭者，廣泛擴散後形成通縮壓力 | 實際交付、相對競爭者持續降本、成本節省傳至售價，且供給增長未被名目需求抵銷 |

聯合假說：持續降本與有效擴張 → 改善每股收益與資源購買力 → 增強交易對手接受股權的意願 → 以股權取得更多生產資源 → 再改善成本。每一箭頭都是待驗證關係，理論 002 成立不代表理論 001 必然成立。

「以股權取代法幣」是理論 001 的強版本與長期情境，目前蒐集的交易尚未證明普遍股權計價或日常再支付。「全球持續通縮」是理論 002 的條件情境，不等於所有物價、所有資產同步下跌。

## 統一用語

| 用語 | 本 repo 的意思 |
| --- | --- |
| AI 核心企業 | 模型、軟體、晶片、製造、能源或部署企業；依實際降本與交付能力選樣，不以「頂級模型」作必要條件 |
| 動態成本優勢 | 以重建成本、追趕時間及相對降本速度衡量；不預設永久不可複製的護城河 |
| 完整任務成本 | 固定品質、可靠度與服務範圍下，每項驗收通過產出的成本；須揭露設備、人力、算力、能源、失敗重試及生命週期的計算口徑 |
| 股權動員資源 | 股權融資支應採購與直接股權支付的上位概念；兩者的證據不可混用 |
| 股權交換力 | 交易對手接受股份作為直接交易對價的能力 |
| 產品定價權 | 在價格、品質與供給決策中保留需求及利潤的能力；不只指漲價，也可能表現為降價仍獲利 |
| 股權計價與貨幣功能 | 商品直接以股份標價、股份可被第三方再收取與支出；不同於一次性的換股收購 |
| 每股價值與投資報酬 | 需分開評估稀釋、必要投入、負債、買進估值及實際股價，不以公司規模增長代替 |

本 repo 統一使用「實體 AI」，包含前述對話中的「物理 AI」。

## 證據與修訂規則

- **來源事實**：附原始來源、資料期間、幣別與單位；公司自述不等同獨立驗證。
- **理論推演**：標明條件及可能失效的環節，不冒充已發生結果。
- **數字示例**：標明純假設，與企業財務數字分開。
- **缺少資料**：標示未知；不把沒有找到證據寫成已證明不存在。
- **交易進度**：分開核准、簽約、中間步驟、最終交割及現金實收。
- **資料版本**：頁面日期是查核日，不代表所有資料都是當季；動態榜單只代表該日快照。
