## 核心問題

- AI 能力提升，如何轉化為生產力、營收與現金流？
- 算力、能源、晶片與資料中心的投資，何時能回收？
- AI 軟體與機器人，如何改變人力需求、單位成本與毛利率？
- 成本下降後，價值如何分配給消費者、企業與基礎設施供應商？
- AI 對就業、薪資、所得分配與整體經濟有何影響？

## 研究主題

| 主題 | 分析重點 |
| --- | --- |
| 算力經濟 | 訓練與推論成本、使用率、折舊、能源與資本支出 |
| AI 商業模式 | 訂閱、API、代理服務、定價與單位經濟 |
| 企業生產力 | 工作流程、自動化、成本節省與新增需求 |
| 機器人經濟 | 製造成本、部署、維護、回收期與產能爬坡 |
| 產業價值鏈 | 晶片、資料中心、模型、應用的收益分配 |
| 總體經濟 | 生產力、就業、薪資、物價與資本集中 |

## 分析方法

1. 定義問題、範圍與衡量指標。
2. 記錄資料來源、發布日期、幣別與單位。
3. 分開呈現已確認事實、公司目標與研究假設。
4. 建立保守、基準、樂觀情境，檢查關鍵參數的敏感度。
5. 以後續實際數據驗證，保留修訂原因與日期。

## 研究筆記格式

- **研究日期與問題**：本次要回答什麼？
- **來源與事實**：原始資料連結、日期與適用範圍。
- **假設與模型**：公式、參數、單位與情境。
- **結果與限制**：推論、尚未確定的部分與可能反證。
- **後續追蹤**：哪些新數據會改變結論？

## 研究狀態

目前已建立研究框架、股權交換與 AI 供給型通縮兩個理論假說，並蒐集企業與總體研究來源；尚未建立量化模型。
