# Anthropic、OpenAI：供應商投資與股權動員資源

- 查核日期：2026-11-14（台灣時間）
- 對應理論：[股權交換經濟](../theories/001_equity_exchange_economy.md)
- 待查命題：Anthropic、OpenAI 使用自己的股票支付 NVIDIA、台積電。

## 查核結果

公開資料可確認供應商認購股權，以及股權投資與算力採購並存的合作。以下來源尚不足以確認直接以股票抵付晶片、代工或算力帳款；也不能據此斷言所有合約均不含這類安排。

| 關係 | 已確認資料 | 狀態與證據邊界 |
| --- | --- | --- |
| 台積電 → Anthropic | 2026-11-10 董事會核准最高 5 億美元認購普通股，依 IPO 價格認購。[S1] | 屬投資核准，不等同已交割，也未表示抵銷代工費。 |
| 台積電 → OpenAI | 同日核准最高 5 億美元認購 OpenAI Group PBC 特別股。[S1] | 屬投資核准，不等同以晶圓換股票。 |
| NVIDIA → OpenAI | OpenAI 於 2026-02-27 宣布新投資，其中 NVIDIA 為 300 億美元；同時公布擴大算力合作。[S2] | 支持資本與供應合作並行；公告未證明以股份直接結清 GPU 帳款，也未逐筆證明資金用途。 |
| NVIDIA／Microsoft → Anthropic | 2025-11-18 合作公告：兩者分別承諾投資最高 100 億／50 億美元；Anthropic 同時承諾採購 300 億美元 Azure 算力。[S3] | 為當時公告條款，非 2026 最新累計數；投資、雲端採購與晶片供應分屬不同交易關係。 |

金額均為美元。投資上限、投資公告與完成付款須區分。

## 三種交易形式：不代表必然的演進順序

1. **直接股權支付**：合約明定以股份作為設備、服務或企業收購對價，或以股份清償帳款。
2. **供應商投資加採購**：供應商投入資金取得股權；AI 公司另行支付設備或算力費用。即使資金最終回流供應鏈，現金仍參與結算。
3. **未確認採購連動的策略投資**：已公告投資或核准認購，但目前資料不足以確認特定採購、產能優先權或合約連動。

本次 NVIDIA 合作支持第二種機制的相關要素；台積電公告屬第三種，而且僅確認董事會核准，不預設已持股或完成交割。若要提升為第一種證據，需要付款條款、股份抵帳規定或相關財務揭露。

## 對理論的意義

使用者觀察到的供應鏈持股現象有事實基礎。可進一步提出待驗證假說：

> 頂級 AI 公司以未來收益的所有權吸引資金與供應鏈合作，再將資金投入當下算力與生產資源。

此處統一稱為「股權動員資源」，包含股權融資支應採購與直接股權支付；各自的證據須分開。它與直接股權支付可能共同促進股權經濟，但不能先視為貨幣已消失或被取代。

需要進一步查核：

- 股份是否直接抵付應付帳款？
- 投資是否附帶採購、交付或產能條件？
- 投資與採購是否存在法律上的連動、淨額結算或取消條款？
- 上游供應商接受股權，究竟是收益預期、客戶關係還是其他因素？
- 合作是否改變價格、交期或供應優先權？持股本身不能證明定價權。

## 與 SpaceX 案例的比較

SpaceX 的 Cursor、Mesh Optical 收購已有完成交易的資料；頻譜合約也明列股票作為對價，但仍待最終交割。此處目前確認的是投資核准、投資公告與供應合作，應並列保存，不混成同一交易形式。詳見 [SpaceX 證據集](spacex_equity_resource_exchange.md)，該頁提供收購狀態與來源；通用定義以 [README](../README.md) 為準。
