# 理論 001：股權交換經濟

- 提出日期：2026-11-14
- 原始命題：使用者提出
- 狀態：待檢驗的理論假說
- 下列運作模型、成立條件與研究問題為初步推演，並非已驗證結論。

## 原始命題

> 未來的世界是一個使用公司股票交易各項資源，取代貨幣。

## 命題補充：頂級 AI 公司與規模條件

2026-11-14 使用者補充：「必須是頂級的 AI 公司股票，股權夠大，才有定價權。」

研究範圍因此收斂到少數掌握關鍵 AI 能力與稀缺基礎設施的企業，而非假設所有公司的股票都能普遍流通。「頂級 AI」與「股權規模」是待驗證條件，尚未證明是必要或充分條件。

需分別衡量公司整體股權價值、可交易規模及個別股東持股比例，並區分資源交換力、產品定價權與貨幣地位。

第一個案例：[SpaceX 股權交換資源證據集](../evidence/spacex_equity_resource_exchange.md)。已蒐集股票作為頻譜與 AI 企業交易對價的資料；對普遍股權計價、日常支付及 AI 必要性的推論仍待驗證。

## 理論表述

在 AI 與自動化高度發展的情境下，公司運用算力、能源、機器人與其他資源提供商品及服務。個人與企業以可分割、可轉讓的公司股權支付，交換這些資源與產出。

在這個假說中，股權同時承擔資產持有與交易媒介的功能。個人藉由出售勞務、提供資源或持有資本取得股權，再轉讓部分股權換取消費。

「取代貨幣」需要分開檢驗三項功能：

| 功能 | 股權制度需要解決的問題 |
| --- | --- |
| 交易媒介 | 商家願意接受哪些公司的股權？ |
| 計價單位 | 商品以哪家公司、哪個股權組合或其他尺度標價？ |
| 價值儲藏 | 持有人如何承受估值波動、稀釋與企業失敗？ |

若股權已被廣泛用於支付及計價，它便開始承擔貨幣功能。因此，本理論更精確的研究方向是：公司股權能否取代目前的法幣與銀行存款，成為主要交易制度。

## AI 在理論中的角色

以下屬於待檢驗的機制假設：

1. AI 與機器人提高自動化程度，使資源與生產設備的所有權更直接影響產出的分配。
2. AI 交易代理替使用者處理不同公司股權之間的報價、交換與風險管理。
3. 股權可細分至小額支付需要的粒度，轉移與結算成本足夠低。
4. 供應商之間形成接受股權支付的交易網路。

AI 降低交換的操作成本，並不等於消除股權價格波動、實際資源短缺或治理問題。

## 假想交易

假設某項服務標價為 A 公司 0.01 股，買方持有 B 公司股票；雙方可接受的交換比例為：

**1 股 B = 2 股 A**

忽略費用與滑價，買方支付 0.005 股 B，經交換後，供應商取得 0.01 股 A。

此例直接使用股權間的交換比例。若交易必須先賣成法幣再付款，則只是「以股票作為付款資金來源」，尚未實現完整的股權交換經濟。

## 必須區分的權利

- **公司股權**：代表對公司的所有權權益。
- **商品或服務兌換權**：代表可向供應商兌換約定產出。
- **支付單位**：代表交易雙方接受的結算工具。

這三者不必相同。本理論不假定持有能源公司股票就能直接要求交付電力；若要讓股權直接兌換產出，需要另行定義契約與履約機制。

## 成立條件與主要難題

| 條件 | 尚待解決的問題 |
| --- | --- |
| 廣泛接受 | 消費者與商家為何願意持有不同企業的股權？ |
| 足夠的市場深度 | 大量消費付款是否造成價格衝擊？ |
| 可靠的計價尺度 | 股權匯率持續變動時，薪資、租金與長約如何標價？ |
| 公平的發行與治理 | 增發、稀釋、控制權與支付需求如何協調？ |
| 可執行的權利制度 | 股權轉移、交易爭議、義務與稅款如何處理？ |
| 基本資源取得 | 沒有股權、無法工作者如何取得食物、住房與能源？ |
| 真實產能支持 | 帳面估值上升時，實際商品與服務是否同步增加？ |

**總市值不是可立即交換的資源總量。** 以少量成交形成的價格估算全部股份，並不保證全部持有人能以該價格買到資源。將股票價格推高，也不會直接增加電力、食物、晶片或機器人的數量。

## 待比較的制度版本

| 版本 | 運作方式 | 與原始命題的關係 |
| --- | --- | --- |
| 個別公司股權 | 直接用各公司的股票交易 | 最直接的版本，交換比例與風險較複雜 |
| 股權籃子 | 用多家公司組成的股權組合交易 | 分散單一公司風險，但需要組合管理規則 |
| 股權支持的支付憑證 | 持有股權，另發可支付的憑證 | 支付工具與股權分離，須研究兌換與信用風險 |
| 股權與法幣並存 | 日常支付、儲蓄或企業交易各有不同用途 | 過渡情境，尚未完全取代法幣 |

## 可檢驗的預測與反證

- 若股權支付逐步成為主要制度，應能觀察到商品直接以股權或股權籃子標價，且交易不依賴法幣兌換。
- 若只有賣出股票後以法幣付款，證據支持的是資產變現支付，尚不足以支持貨幣被取代。
- 若使用者長期偏好先換成穩定支付單位，則完整股權支付的假說需要修正。
- 若自動化產出增加，但所有權集中使多數人缺乏購買力，理論還需要補上分配機制。

3. 探討公司向股東分配產出、股權支付與基本資源保障如何互相影響。
